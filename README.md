# LovePersona AI 💕

> **AI 驱动的 MBTI 恋爱人格深度解析系统**

基于深度心理学模型，结合 MBTI 人格理论与依恋心理学，为你生成专属的恋爱人格档案和 AI 形象。

---

## ✨ 核心特性

### 🎯 人格测评系统
- **48 道精心设计的问题**，覆盖 4 大维度
- **李克特 7 点量表**，精确测量人格倾向
- **16 种恋爱人格类型**，每种都有独特的特征和行为模式

### 🎨 AI 形象生成
- **4 种画风选择**：日漫赛璐璐 / 韩漫唯美 / 中国古风 / 复古港风
- **Cel-shaded 平面风格**，清新简洁的视觉效果
- **基于 Google Gemini AI**，生成专属人格形象
- **性别定制**：支持男生/女生不同形象风格

### 📊 深度人格分析
- **人格结构剖析**：深入解读你的核心特质
- **恋爱行为模式**：揭示你在亲密关系中的表现
- **优势与盲点**：帮你了解自己的长处和需要改进的地方
- **相处建议**：提供实用的恋爱指导

### 💑 CP 匹配实验室
- **智能匹配算法**：分析两个人格的契合度
- **5 大场景模拟**：情感需求、沟通方式、冲突处理、社交能量、金钱观
- **互动式选择器**：按分类展示 16 种人格，方便快速选择

### 📚 知识库
- **维度解析**：详细解释 E/I、N/S、F/T、A/D 四大维度
- **书单推荐**：针对不同人格类型的专属阅读清单
- **理论基础**：深入了解依恋理论和人格心理学

### 🗂️ 人格图鉴
- **16 种人格完整展示**
- **按类别浏览**：理性分析家(NT) / 理想外交家(NF) / 务实守护者(ST) / 感性探险家(SF)
- **实时形象生成**：切换性别和画风，即时查看效果

## 🚀 快速开始

### 环境要求
- Node.js >= 20.19.0 或 >= 22.12.0
- npm >= 10.0.0

### 安装步骤

1. **安装依赖**
```bash
npm install
```

2. **配置环境变量**

创建 `.env` 文件并添加你的 Gemini API Key：
```env
VITE_GEMINI_API_KEY=your_api_key_here
```

> 💡 获取 API Key：访问 [Google AI Studio](https://makersuite.google.com/app/apikey)

3. **启动开发服务器**
```bash
npm run dev
```

4. **打开浏览器**

访问 `http://localhost:3000`

## 🎮 使用指南

### 1️⃣ 开始测试
1. 选择性别（男生/女生）
2. 点击"开始测试"按钮
3. 回答 48 道题（每页 6 题）
4. 使用 7 点李克特量表选择你的答案

### 2️⃣ 查看结果
- 自动生成你的恋爱人格类型
- 查看 AI 生成的专属形象
- 阅读详细的人格分析报告
- 下载形象（带/不带水印）

### 3️⃣ 切换画风
- 点击导航栏的"画风"按钮
- 选择喜欢的风格
- 重新生成形象

### 4️⃣ CP 匹配
- 进入"匹配"页面
- 选择两个人格类型
- 点击"开始分析"
- 查看详细的匹配报告

### 5️⃣ 浏览图鉴
- 进入"图鉴"页面
- 按类别浏览 16 种人格
- 点击任意人格查看详情

## 🧠 人格类型系统

### 四大类别

#### 💜 理性分析家 (NT)
- **ENTA** - 理性浪漫策划者（脑补大师）
- **ENTD** - 自由理性主义者（恋爱玩家）
- **INTA** - 忧虑分析者（闷骚军师）
- **INTD** - 独立思想者（冰山学者）

#### 💚 理想外交家 (NF)
- **ENFA** - 热情浪漫主义者（黏人小狗）
- **ENFD** - 自在人情主义者（花蝴蝶）
- **INFA** - 敏感理想家（痴情诗人）
- **INFD** - 矜持浪漫主义者（高冷诗人）

#### 💙 务实守护者 (ST)
- **ESTA** - 强势保护者（护短狮子）
- **ESTD** - 冷静执行者（钢铁直男/女）
- **ISTA** - 忠诚守卫者（闷骚骑士）
- **ISTD** - 独立实干者（冰山劳模）

#### 💗 感性探险家 (SF)
- **ESFA** - 忠诚守护者（黏人小太阳）
- **ESFD** - 随和照顾者（中央空调）
- **ISFA** - 温柔守护者（小绵羊）
- **ISFD** - 温和自持者（佛系伴侣）

### 四大维度

1. **E/I (外向/内向)** - 能量来源
2. **N/S (直觉/实感)** - 信息处理方式
3. **F/T (情感/理性)** - 决策依据
4. **A/D (焦虑/回避)** - 依恋模式（创新维度）

## 🎨 画风详解

### 日漫赛璐璐 🔵
Cel-shaded 平面动画风格，鲜明的轮廓线和纯色填充，经典日系动漫美学。

### 韩漫唯美 💗
现代韩式 Webtoon 风格，精致的平面插画效果，时尚优雅的视觉表现。

### 中国古风 💚
传统汉服与古典元素，简约优雅的平面设计，诗意浪漫的东方美学。

### 复古港风 🧡
90年代香港漫画风格，浓重的墨线和霓虹色彩，怀旧复古的视觉体验。

## 🔧 开发指南

### 添加新人格类型

在 `constants.ts` 的 `PERSONALITIES` 对象中添加新人格配置。

### 添加新画风

在 `constants.ts` 的 `ART_STYLES` 中添加新画风的提示词配置。

### 修改问题

在 `constants.ts` 的 `QUESTIONS` 数组中编辑问题内容和维度映射。
